# Aegis – Ad & Tracker Blocker

Aegis is a privacy-focused ad and tracker blocker for Chrome, built on the uBlock Origin Lite filtering engine and Manifest V3.

## Links

- [Privacy Policy](privacy.html)
- [Source code](https://github.com/Ponze08/aegis-adblocker)
- [Report an issue](https://github.com/Ponze08/aegis-adblocker/issues)

Aegis performs filtering locally in the browser and does not include analytics or telemetry.
