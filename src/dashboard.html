            Custom filter rules

            Write filters in uBlock Origin syntax, one per line. Lines starting with ! are comments.

            Network filters (||…^) always work. Cosmetic filters (##…) and scriptlets (##+js(…)) written here also need the Allow User Scripts switch, on the browser's details page for Aegis. To simply hide something, the Hide tool of the popup works without it.
            0 filters
            Filter syntax cheat sheet
            ||ads.example.com^Block everything from a domain
            ||example.com/banner/*Block addresses matching a pattern
            example.com##.promo-boxHide an element on one site (CSS selector, needs User Scripts)
            ##.cookie-popupHide an element on every site (needs User Scripts)
            @@||example.com^Never block this domain
            example.com##+js(set-constant, adsEnabled, false)Run a uBlock Origin scriptlet (needs User Scripts)

            Full reference: uBlock Origin static filter syntax.

            Aegis

            Version

            A friendly ad & tracker blocker built on the engine of uBlock Origin Lite.

            How Aegis blocks

            • Network rulesFilter lists are compiled into rules the browser enforces itself, before a request leaves your computer. Fast, private, and nothing runs on each request.
            • Cosmetic filteringHides the empty boxes and banners left behind on the page.
            • ScriptletsSmall fixes injected into pages to defuse anti-adblock walls and video ads.
